# BG02 Studio

[English README](./README.en.md)

電子缶バッジ **BG02 (E-BADGE)** 向けの、**完全ローカル動作・外部サーバー通信ゼロ・TypeScript 製 PWA** です。  
Web Bluetooth API を利用し、ブラウザ上（Chrome / Edge）から直接画像を円形フレームへ位置合わせして生成・転送できます。

---

## 作成の経緯・背景

1. **端末設定画面における日本語表示の問題**  
   実機 `BG02` 本体の設定画面では日本語を選択できますが、翻訳が不自然なだけでなく**文字が消える・文字化けする箇所**があり実用的ではありませんでした。当初は端末内蔵フォントの置き換えやファームウェア（FW）改変を検討しました。
2. **公式アプリの過剰な権限・通信への懸念**  
   公式 Android アプリ（`com.legend.smartwatch.electronicbadge.android` / `SuperBand 2.1.25`）を調査したところ、位置情報（Baidu Location SDK 等を含む）、連絡先、通話状態、通知リスナー、マイク録音、カメラ、外部通信など、バッジに画像を送る用途に対して過剰な権限・外部 SDK が含まれていることが確認されました。
3. **FW 改変の断念と「安全に置き換える」方向への転換**  
   - 実機 FW は暗号署名検証機構（ECC-256 系 OTA 認証）があり、公開 FW イメージや文鎮化時の復旧手段もないため、FW 改変は現実的ではありませんでした。
   - 一方で調査を進める中で、カスタム画像表示（`WatchTheme3`）は端末フォント ROM に依存せず、**240×240 の Baseline JPEG 画像を BLE 経由で転送して表示する仕組み**であることが判明しました。
   - 既知のオープンソース実装 `openfantasymap/badger`（旧 `baji` プロトコル `PRODUCT_ID = 0x25`）は本機 `BG02` と非互換だったため、プロトコル解析結果をもとにゼロから安全な TypeScript PWA として構築しています。

詳細な記録は [docs/BACKGROUND.md](./docs/BACKGROUND.md) および [docs/PROTOCOL.md](./docs/PROTOCOL.md) を参照してください。

## できること（機能）

- **100% ローカル・外部API通信ゼロ**
  - 画像の編集・JPEG生成・送信処理はすべてブラウザ内で完結し、外部サーバーへのデータ送信やアップロードは一切行いません。オフライン起動できる軽量 Service Worker（登録スコープ限定キャッシュ）にも対応しています。
- **迷わない 5 画面ワークフロー（モバイル 1 カラム ＋ PC 60/40 編集）**
  1. **ホーム**: 起動ロゴの後、初回は矢印付きの案内が表示されます。未接続時は **バッジを接続**、接続後は **写真を選ぶ** が主操作です。**接続せずに試す** からもサンプル写真や手元の写真を編集できます。
  2. **写真を整える (`2. 写真を整える`)**: 円形プレビューでの 1本指/マウスドラッグ移動・2本指ピンチ/ホイール拡大縮小・90°回転・キーボード矢印/±微調整・文字入れ（日本語フォント＆縁取り）に対応し、詳細スライダーや SOF0 検査は折りたたみ欄に整理しています。
  3. **バッジに送る (`3. バッジに送る`)**: 送り先バッジの明示確認（カスタム枠 `slot=5538` の上書き注記あり）、転送中プログレス（完了応答待ち切り替え）、失敗時の同一画像ワンタップ再送、容量/電池不足/充電中（`code=4`）の案内を行います。
  4. **登録済みバッジ**: 右上からバッジの一覧を開けます。名前、接続状態、電池残量（実測・前回取得・未確認）を確認できます。
  5. **バッジ詳細**: ホームまたは一覧の **管理** から、そのバッジの名前、接続、登録解除、診断を操作できます。再接続の設定やブラウザー側の接続許可を解除する手順も開けます。
- **Bluetooth なしの編集・ローカル JPEG 保存に対応**
  - Web Bluetooth 非対応環境（iOS Safari 等）やバッジ未接続時でも、画像の円形切り抜き・文字入れ・`240×240` Baseline JPEG 保存はそのまま利用できます。

## 対応 OS・ブラウザ & API サポート表

| 環境 | Web Bluetooth 送信 | `getDevices()` / `forget()` | 画像編集・JPEG 保存 |
| :--- | :--- | :--- | :--- |
| Windows / macOS / Linux (Chrome / Edge) | 対応（HTTPS / localhost） | ブラウザ版・フラグに依存（不可時はピッカー接続・手動解除を案内） | 対応 |
| Android (Chrome / Edge) | 対応（位置情報権限・BT ON 必須） | Chrome バージョンに依存 | 対応 |
| iOS / iPadOS Safari | **非対応** | 非対応 | **対応**（ローカル JPEG 保存可） |

- **実機確認済み対象機仕様**: `BG02` (`Manufacturer: LJ733_V1_BadgeOK` / `Hardware: LJ733_MB_V1.5` / `Firmware: V35922` / `240×240` Round / `algorithm=4 (JPEG)`)。統合後の画面と送信は、Chromium上で2台の模擬バッジを使って検証しています。統合後の実機転送は未検証です。

## できないこと・制約事項

Web Bluetooth API および端末側ファームウェア・OS 仕様上、以下は対応できません（または対象外です）。

1. **端末内蔵フォントの置き換え・FW 改変・本体設定画面の日本語修正**
   - 暗号署名された FW の書き換えは文鎮化リスクが高く非対応です。文字化けを避けたい表示内容は、PWA 側で画像化して送信することで回避します。
2. **初期プリセット画像の削除**
   - 実機が使用する `mywatchsdklib` プロトコルには端末内画像の削除コマンドが存在しません。カスタム送信は固定スロット（`watchID = 5538`）を上書きする挙動となります。
3. **スマートフォンの着信・SMS・他アプリ通知の転送**
   - ブラウザ（PWA）は Android の `NotificationListenerService` 等にアクセスできないため、通知連携は実装できません。
4. **バックグラウンド常駐・iOS Safari での動作**
   - **Web Bluetooth API は Desktop / Android の Chrome・Edge 専用**であり、**iOS Safari は非対応**です。またブラウザを完全に閉じると BLE 接続は切断されます。
5. **クラウド依存機能（AI 同時通訳・公式 OTA アップデート等）**
   - 外部クラウド通信を行わない設計ポリシーおよび公式サーバー仕様上の理由から搭載しません。
6. **動画 (AVI) 転送・時刻同期・端末を探す・一覧取得（`0x20/0x03`）など**
   - 公式 APK 内にコマンド定義はあるものの実機 `BG02` での挙動が未検証の機能は、安全のため初期リリース対象外としています（検証用ツール側で確認後に拡張検討）。

## 対応ブラウザ・動作要件

- **必須ブラウザ**: Google Chrome / Microsoft Edge（Windows, macOS, Linux, Android）
- **通信条件**: `https://`（GitHub Pages 等）または `http://localhost`
- **対象確認済み実機情報**:
  - デバイス名: `BG02`
  - Manufacturer: `LJ733_V1_BadgeOK` / Hardware: `LJ733_MB_V1.5` / Firmware: `V35922`
  - Display: `240×240` Round / `algorithm = 4` (`JPEG`)

## 開発・ビルド・GitHub Pages デプロイ

```bash
npm install
npm run dev       # ローカル開発サーバー
npm run typecheck # TypeScript 型チェック (tsc --noEmit)
npm test          # Vitest 単体テスト実行
npm run build     # TypeScript 型チェック + 本番ビルド (dist/) + dist/sw.js 自動生成
npm run docs      # TypeDoc API ドキュメント検証・生成
```

- GitHub Pages 公開時は相対パスベース（`base: './'`）で静的ファイル一式（`dist/`）を配信します（`.github/workflows/deploy.yml` 同梱）。
- 本番ビルド時に生成される `dist/index.html` には外部通信を禁止する厳格な `Content-Security-Policy` メタタグが自動付与されます。
- ビルド後に `node tests/browser-smoke.mjs` を実行すると、Playwrightで接続、編集、送信までを確認できます。別途用意したPlaywrightとChromeは `PLAYWRIGHT_MODULE` と `CHROME_EXECUTABLE` で指定できます。

## 開発方針（ドキュメント規約）

- すべてのクラス・関数・変数・定数に **TypeDoc (`/** ... */`)** を記載します。
- 通信仕様のクセ（20バイト分割、`0xDC` ACK、送信完了後タイマーの考え方、JPEG サイズ目安など）といった**コードだけでは読み取れない意図**を必ずコメントとして残します。
